# 研发项目状态中文显示设计

## 目标

修正研发中心“研发项目数据库”中编辑项目的状态下拉框，使状态显示为中文，并确保保存后数据库表格显示与编辑选项一致。

## 范围

- 同步修正 `frontend/project.html` 与 `frontend/frontend/project.html` 两个页面副本。
- 统一项目状态的编码值与中文标签配置：`init/预项目`、`executing/进行中`、`completed/已完成`、`paused/暂停`、`cancelled/取消`。
- 编辑弹窗和表格继续以编码值提交/筛选/统计，以中文标签展示。
- 不修改后端接口、数据库字段、历史数据或其他项目状态。

## 实现方案

前端定义状态选项配置，并由表单渲染与内联编辑共同读取。下拉 `<option>` 的 `value` 使用状态编码，文本使用中文标签；列表通过同一映射渲染中文。这样既保持已有 API 契约，也避免两个页面副本出现展示差异。

## 数据流

1. API 返回项目 `status` 编码，例如 `executing`。
2. 编辑表单根据编码选中对应选项，并显示“进行中”。
3. 用户保存时表单提交 `status: "executing"`。
4. 列表刷新后继续根据相同映射显示“进行中”。

## 验证

- 静态检查两个页面都包含完整的中文状态映射，并且状态选项的 value 仍为编码。
- 使用 Node 脚本验证状态配置覆盖五种编码、中文标签正确，且表单代码不会把中文标签作为提交值。
- 运行项目已有可执行的回归测试/语法检查，确认无新增错误。
