# 销售快捷服务系统——询价模块 MVP 落地详细方案（首期核心）

## 一、模块定位与建设目标

询价模块为**销售快捷服务系统首个核心落地模块（MVP一期重点）**，是全业务链路的源头入口，承载「客户咨询→需求录入→智能核价→快速报价→数据沉淀→初步转化分析」全流程能力，所有后续样品、项目、订单业务均从询价数据流转延伸，是整套系统数据底座与业务闭环的基石。

本模块严格遵循系统顶层架构规范：**主动录入、主动获数为核心，批量导入/批量修正为辅助**；适配全局「大数据库\+二级子小数据库」分层架构，采用**松耦合模块化架构设计**，支持**可独立拆分运行、可全模块合并联动**，既可单独作为询价系统使用，也可后续与样品、项目、订单模块无缝拼接为完整销售快捷服务系统，同时支持数据穿透下钻、报表分析、人员能力考核、问题PDCA改善。

**核心建设目标（新增可分可合模块化目标）**：

- 标准化客户询价承接流程，统一报价口径，杜绝报价混乱、参数错乱；

- 实现产品参数、物料数据、核价标准自动带出，大幅提升询价报价效率；

- 完整沉淀询价全链路数据，为后续转化、人员考核、培训赋能提供源头数据；

- 预留样品、项目、订单模块数据接口，支持业务一键递进流转；

- **模块化松耦合设计**：支持模块独立部署、单独使用，也可与后续样品/项目/订单模块合并集成、全域联动，适配不同阶段、不同使用场景；

- 轻量化MVP落地，功能刚需、流程简洁、可快速上线、可迭代拓展。

## 二、模块整体架构（适配系统顶层规范）

### 2\.1 数据准入规范（强制执行）

1、日常业务核心：全部以**销售主动录入询价信息、系统主动匹配参数、流程主动落库**为唯一正规数据来源，保证数据真实、可溯源、可考核。

2、辅助兜底能力：开放**批量导入、批量修改**功能，仅用于系统初始化建库、历史询价数据迁移、大批量参数统一纠错更新，**不替代日常主动业务操作**。

3、数据口径隔离：批量操作数据单独日志留痕，不参与常规转化率、人员能力考核统计，保证绩效考核公正严谨。

### 2\.2 数据库层级归属

本模块数据归属系统顶层**业务交易大数据库**，独立对应二级子库：**询价业务小数据库**，同时联动**基础资源大数据库**下的产品物料核价小数据库、人员权限能力小数据库，实现参数复用、数据互通。

所有询价数据统一分层存储，支持后续全维度取数、穿透下钻、报表分析、链路转化统计。

### 2\.3 业务链路定位

处于全业务流程第一层级：**客户初步咨询 → 询价模块录入核价 → 按需流转样品模块 → 项目模块跟进 → 订单模块成交**，所有询价单据终身可溯源后续业务，形成链路绑定关系。

本询价模块采用**行业标准松耦合模块化架构**，具备「**拆分独立运行、合并全域联动**」双模式能力，是整套系统模块化落地的标准单元，所有后续子模块均统一该架构标准。

- **独立数据库闭环**：自带完整「询价业务小数据库」，无需依赖样品、项目、订单数据，单独完成数据存储、取数、统计、报表、看板分析。

- **独立业务闭环**：可单独完成客户咨询、询价录入、智能核价、快速报价、状态管控、台账管理、数据复盘、PDCA改善全流程。

- **独立协同闭环**：自带RM即时通讯能力，询价问题独立沟通、独立留痕、独立闭环。

3.4 完整标准询价业务全流程（定制闭环流程）
本模块固化企业专属询价闭环流程，全程线上流转、数据留痕、权责清晰，严格遵循「销售发起→参数选型→自动生成配置→研发核价→价格调整→生成报价单」完整业务逻辑，同时联动两大基础数据库，适配模块化可分可合架构，独立运行可闭环，合并运行可联动下游模块。
标准完整业务流转步骤：
第一步：销售发起询价，模糊检索选型：销售承接客户需求，主动新建询价单，录入客户、需求交期、询价数量、定制要求等基础信息；支持产品名称/产品系列模糊搜索，系统自动匹配并下拉带出对应产品型号列表，销售精准选定对应产品型号，锁定核心产品参数基准。
第二步：证书等级选型配置：型号选定后，系统弹出证书配置选型项，销售选择证书合规属性，包含两大核心选项：证书是否符合标准（是/否）、证书等级（国标/行标/企标/无证书）；选型完成后，系统自动匹配对应证书配套参数与合规要求，绑定至当前询价单据。
第三步：自动生成专属产品配置表：完成型号、证书选型后，系统联动底层物料库、核价库两大基础库，自动调取对应产品标准物料清单、加工工艺、成本参数、合规配置，一键生成完整产品配置表；区分固定标准参数（不可修改）与客户定制参数（可手动微调），所有修改全程留痕，保证配置真实可溯源。
第四步：流程推送研发核价：销售确认配置表无误后提交单据，系统自动流转推送至研发人员，进入专业核价环节，实现业务分工闭环。
第五步：研发核价与价格调整：研发接收待核价单据，系统默认自动引用核价库标准价格、物料成本、加工成本、损耗成本回填至配置表；研发可根据产品定制需求、工艺变更、物料波动等实际场景，手动微调价格参数，核对所有成本、报价维度数据，确认核价结果。
第六步：配置表固化，生成正式报价单：研发核价确认完成后，最终价格自动固化至产品配置表，系统一键将配置表数据转换为标准化报价单，完整同步产品参数、证书等级、物料配置、价格明细、有效期等核心信息。
第七步：报价单推送销售，业务闭环：报价单生成完成后推送至销售端，销售可预览、导出、发送客户，完成询价报价全流程闭环；所有流程数据自动沉淀至对应数据库，支撑后续台账查询、数据穿透、转化分析、人员考核。
3.5 底层基础库体系（双库支撑、系统+Excel双适配）
询价模块搭建两大核心基础库，为全流程核价、配置、报价提供底层数据支撑，支持系统在线维护、Excel批量导入导出，遵循「主动录入为主、批量修正为辅」数据规范，单模块独立使用可闭环，全模块合并可全局共享。
3.5.1 物料库（核心基础库1）
存储企业所有标准化物料、加工物料数据，是产品配置、成本核算、BOM拆解的核心数据源，覆盖常规物料、定制加工物料全品类。
核心存储内容：物料编号、物料名称、规格参数、材质、单位、标准成本、加工工艺要求、加工损耗、供应商信息、物料状态（正常/停产/定制/改版）。
核心作用：询价选型后自动带出配套物料清单，支撑研发精准核算物料成本；支持物料数据新增、修改、批量更新，统一全系统物料标准，杜绝参数错乱。
3.5.2 核价库（核心基础库2）
存储所有产品、不同证书等级对应的标准化核价数据，沉淀所有成品价、加工价、成本价，是研发快速核价、统一报价口径的核心依据。
核心存储内容：产品系列、产品型号、对应证书等级、标准物料成本、人工加工费、工艺成本、预估损耗、最低限价、标准报价、核价版本号、价格生效时间。
核心作用：研发核价一键引用标准价格，减少重复核算；支持价格微调、版本追溯、历史价格溯源；所有报价均基于核价库生成，保证报价标准化、规范化、可追溯。
