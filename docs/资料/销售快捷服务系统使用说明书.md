# 销售快捷服务系统 使用说明书

> 简约版 · 快速上手指引

---

## 一、登录系统

1. 打开浏览器，访问系统地址：`http://<系统地址>`
2. 输入账号、密码
3. 点击 **登录** 进入主界面

> 首次登录请及时修改默认密码

## 二、界面说明

| 区域 | 功能 |
|------|------|
| 顶部菜单栏 | 模块切换、个人中心、退出 |
| 左侧导航 | 业务功能分类 |

## 三、核心功能

### 1. 客户管理
- 新增 / 编辑 / 删除客户信息
- 客户分类标签、跟进记录
- 快捷键：`Ctrl + N` 新增

### 2. 订单管理
- 创建订单、选择商品
- 订单状态跟踪
- 导出 Excel：`Ctrl + E`

### 3. 快捷开单
- 一键调取常用商品
- 支持扫码录入
- 自动计算金额

### 4. 数据统计
- 销售日报 / 月报
- 业绩排行
- 图表导出

## 四、常用操作

| 操作 | 路径 / 快捷键 |
|------|--------------|
| 新建客户 | 客户管理 → 新增 |
| 查询订单 | 订单管理 → 搜索框输入单号 |
| 打印小票 | 订单详情 → 打印 |
| 退出登录 | 右上角头像 → 退出 |

## 五、常见问题

**Q1：忘记密码怎么办？**
> 联系系统管理员重置，或点击登录页"忘记密码"。

**Q2：数据无法保存？**
> 检查网络连接，确认必填项已填写。

**Q3：打印无响应？**
> 检查打印机连接与驱动。
