📋 填写规则（点击展开/收起）▶
  • 人工编码：留空将自动生成（格式 LR年月-流水号，如 LR202607-0001）；手动填写时不可重复
  • 员工姓名 *：必填；工号、部门、岗位 可手填或从历史记录选择
  • 人工类型：决定合计金额的计算方式
    • 计时：合计 = 单价(时薪) × 工时 + 加班费 + 补贴 + 奖金 + 社保 + 公积金
    • 计件：合计 = 单价(计件单价) × 件数 + 补贴 + 奖金 + 社保 + 公积金
    • 月薪/外包/临时：合计 = 基本工资 + 加班费 + 补贴 + 奖金 + 社保 + 公积金
  • 工作日期：实际工作日期；归属月份留空时按工作日期自动推导为 YYYY-MM
  • 工时/件数/单价/基本工资：按类型填写对应项（计时填工时，计件填件数）；改任一数值时合计金额自动重算
  • 社保/公积金：填企业承担部分（不含个人代扣）
  • 合计金额：系统自动计算，无需手填
  • 带 * 为必填项，其余可留空
