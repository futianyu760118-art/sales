外部 ERP 工价审核表对接配置


对接 ERP 工价审核表接口，启用后可一键同步"成品工价"主数据（按 bom_no upsert：ERP 有值更新；ERP 无值保留本地人工录入）。







































使用说明（HJ 基础数据库-对外接口）


    

  • 接口约定：所有请求走 GET，需携带 X-API-Key 头（由环境变量 EBMS_EXTERNAL_API_KEY 注入，或在配置中填写）
    • 

  • 默认数据源：
  
      
    
    • 工价明细：t_BOSAssemblyPriceEntry（含 FItemID, FPrice, WProcedure, FNOTE）
      • 
    
    • 产品主数据：t_ICItemCore（含 FItemID, FNumber, FShortNumber, FName）
      • 
    
    • 工价头表：t_BOSAssemblyPrice（提供 FDate 生效日）
      • 
  
    

    • 

  • 字段映射：FShortNumber → bom_no（主匹配键），FNumber → product_code，FName → product_name，FPrice → labor_rate，WProcedure/FNOTE → remarks
    • 

  • upsert 策略：按 bom_no 匹配；ERP 有值且与本地不同 → 更新；ERP 无值/为 0 → 保留本地人工录入值（不覆盖）
    • 

  • 同步后状态：默认 pending（待审核），需在「工价明细」中审批 approved 后才会被订单分析 calcPlanCost 注入
    • 

  • 如需换其他表：修改「工价数据表」字段名（如 StdCost_ItemStdPriceEntry、t_Price 等），保存后重新测试连接
    • 

  • 排查工具：点击「🔌 测试连接」分 3 步诊断（连通性 / 鉴权 / 数据可达）；同步返回的 sample 字段展示前 3 条原始数据
    •

📋 填写规则（点击展开/收起）▶

  
    
    
  • BOM编号 *：主匹配键（与订单多产品 order_products.bom_no 对齐），如 JFS22-B1WB10S27-46-01
    • 
    
  • 产品编码/名称：冗余字段，便于检索与兜底匹配
    • 
    
  • 工价(元/台) *：单台成品装配人工成本，订单分析 calcPlanCost 会按 工价 × 数量 注入到 BOM 根节点
    • 
    
  • 计价方式：标准工价（长期稳定）/实测工价（实测统计）/暂估工价（新工艺未稳定）
    • 
    
  • 工艺成本：单台工艺附加成本，默认归入"人工"（如属外协制具可由订单分析改入费用）
    • 
    
  • 生效日/失效日：管理工价版本，留空=长期有效；同 bom_no 已审核记录的生效区间不可重叠
    • 
    
  • 审核状态：pending 待审核（默认）→ approved 已审核（被订单分析消费）→ disabled 已停用
    • 
    
  • 带 * 为必填项
    •
